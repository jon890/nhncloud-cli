# 메이저 갱신 판단

3단계에서 메이저 대상마다 읽는다. 5단계 보고의 이유 표 형식도 여기가 소유한다.

## 릴리스 노트 찾기

저장소 주소와 새 버전의 Node 하한을 먼저 얻는다.

```bash
PKG=""   # 패키지 이름을 넣는다
npm view "$PKG" repository.url engines --json
```

릴리스 본문을 읽는다. 경로에 쿼리 문자열이 있으므로 따옴표로 감싸야 zsh 가 `?` 를 glob 으로 읽지 않는다.

```bash
REPO=""    # owner/name 형식의 저장소를 넣는다
MAJOR=""   # 목표 메이저 숫자를 넣는다
gh api "repos/$REPO/releases?per_page=30" --jq ".[] | select(.tag_name | test(\"^v?${MAJOR}[.]0[.]0$\")) | .body"
```

Release 가 없으면 저장소의 `CHANGELOG.md` 를 읽는다. 둘 다 없으면 compare 링크를 적고 보류한다.

## 판정 기준

| 확인할 것 | 보는 곳 | 판정에 주는 영향 |
|---|---|---|
| dependencies 의 Node 하한 | 새 버전 `engines.node` 와 우리 `package.json` 의 `engines.node` | 새 버전이 더 높으면 사용자 설치 환경의 하한이 바뀐다. 사용자에게 묻고 정하기 전에는 올리지 않는다 |
| devDependencies 의 Node 하한 | 새 버전 `engines.node` 와 `ci.yml`, `release.yml` 의 `NODE_VERSION` | 사용자 설치본에 들어가지 않으므로 우리 `engines.node` 가 아니라 워크플로의 Node 와 비교한다 |
| 빌드 target | dependencies 가 요구하는 문법과 `tsup.config.ts` 의 `target` | 번들에 들어가는 코드가 target 보다 새 문법을 쓰면 빌드 설정까지 바꿔야 한다 |
| 범위 안 대안 | 2단계 시험 결과 | 범위 안에서 이미 풀리는 취약점이면 메이저의 보안 이득은 없다 |
| 자체 타입 제공 | 새 버전 패키지의 `types` 필드 | `@types/*` 를 빼도 되는지는 `trial-update.mjs` 에 제거 옵션이 없으므로 수동으로 확인한다. 임시 worktree 는 메인 checkout 아래라 모듈 해석이 상위 `node_modules` 로 올라가, 패키지 제거 시험은 위양성이 날 수 있다 |
| 진입점 변경 | 새 버전 `exports` 맵 | 바뀌었으면 `src/` 에서 깊은 경로 import 를 grep 한다 |
| 시험 결과 | `trial-update.mjs` 의 tsc, test, build, verify-package 로그 | 오류 건수와 위치를 수정량으로 적는다 |

## 판정

| 판정 | 조건 |
|---|---|
| 올림 | 시험이 모두 통과했고 보안 이득이나 기능 이득이 하나 이상 있다 |
| 코드 수정 후 올림 | 시험 실패의 원인이 우리 코드이고, 수정량이 로그 위치로 확정되며 이득이 하나 이상 있다 |
| 보류 | Node 하한이나 target 처럼 사용자에게 정책을 물어야 하는 항목이 있거나, 릴리스 노트를 찾지 못했거나, 수정량이 확정되지 않았다 |

- 보안 이득도 기능 이득도 없는 메이저는 시험이 통과해도 「올림」으로 판정하지 않는다. 「이득 없음, 시험 통과」로 적어 사용자가 정한다. 옛 메이저의 지원 종료일을 알면 함께 적는다.
- 보안 사유가 있는 메이저는 보류해도 보고 첫머리에 적는다.

## 이유 표

버전을 바꾸는 단위마다 붙인다. 커밋 본문에는 패키지마다 한 줄씩 옮긴다.

| 패키지 | 변경 | 이유 |
|---|---|---|

이유 칸은 아래 셋 중 하나로 채운다.

- 해소하는 취약점: 무엇이 일어나는 문제인지, 등급, 이 CLI 의 어느 기능이 그 코드를 쓰는지
- 이 CLI 가 쓰는 경로에 닿는 변경: 릴리스 노트의 어느 항목이 어느 코드에 해당하는지
- 둘 다 없으면 「보안 사유 없음. 같은 범위 안의 최신화」

advisory 제목을 그대로 옮기지 않고 무엇이 일어나는지로 풀어 쓴다.
