## ADR-025: 공개 스킬 수명주기와 관리 저장소

**결정**: 공개 스킬은 Node 전역 패키지 경로가 아니라 사용자 데이터 디렉터리의 버전·콘텐츠 해시별 불변 저장소에 설치한다.
Claude Code의 스킬 경로는 이 저장소를 가리키는 심볼릭 링크로 유지하고 `nhncloud skills update`가 새 저장소 준비 후 링크를 원자적으로 전환한다.

**맥락**: Node 버전 관리자는 전역 npm 경로를 버전별로 분리할 수 있다.
패키지 내부를 직접 가리키는 기존 링크는 이전 CLI에 남을 수 있으며, 링크 존재만 검사하면 오래된 스킬과 사용자 수정본을 구분하지 못한다.

**대안 기각**:

- npm `postinstall` 자동 갱신은 설치 스크립트 비활성화, 비대화형 환경과 권한 정책 때문에 필수 계약으로 신뢰하지 않는다.
- 현재 npm 패키지 직접 링크는 같은 전역 설치 경로에서만 자동으로 갱신되며 Node 버전이나 전역 경로 변경을 견디지 못한다.
- 단일 가변 복사본은 설치 중 실패와 사용자 수정 여부를 판별하기 어렵고 이전 정상본을 보존하지 못한다.

**트레이드오프**: npm 갱신 후 사용자가 `nhncloud skills update`를 명시적으로 실행해야 한다.
대신 매니페스트와 콘텐츠 해시로 오래된 설치·수정·손상을 구분하고, 새 저장소 준비와 활성 링크 전환을 분리해 부분 설치 노출을 막는다.

**적용 범위**: 기존 패키지·저장소 직접 링크는 관리 가능한 이전 설치로 판정해 `--force` 없이 전환한다.
관리되지 않은 항목과 수정·손상된 관리 저장소는 기본적으로 보존하고 `--force`에서만 백업 후 교체한다.
이전 버전 자동 삭제, npm `postinstall`과 별도 롤백 명령은 범위에서 제외한다.
