# ADR-035: 필수 옵션 누락을 입력 오류로 정규화한다

- **결정**: Commander의 `requiredOption`은 유지하고, 명령 트리 전체에 공통 오류 변환을 적용한다.
  - `commander.missingMandatoryOptionValue`만 `EXIT_PARAM_ERROR`인 종료 코드 3으로 바꾼다.
  - Commander가 출력하는 기존 오류 문구는 바꾸지 않고 stderr에 한 번만 남긴다.
  - 알 수 없는 옵션과 불필요한 인수 같은 다른 Commander 문법 오류는 종료 코드 1을 유지한다.
  - 도움말과 버전 출력은 종료 코드 0을 유지한다.
  - 명령 내부의 수동 필수값 검증은 기존 오류 문구와 종료 코드 3을 유지한다.
- **맥락**: 같은 명령에서도 수동으로 검사한 필수 옵션을 빠뜨리면 종료 코드 3이지만, Commander의 `requiredOption`을 빠뜨리면 종료 코드 1이었다.
  자동화는 두 경우를 모두 사용자가 고쳐야 하는 입력 오류로 다뤄야 하므로 검증 구현에 따라 종료 코드가 달라지면 안 된다.
  현재 `requiredOption`은 여러 서비스 명령에서 사용하며 조기 검증과 도움말의 필수 표시를 함께 제공한다.
- **대안 기각**:
  - 모든 `requiredOption`을 일반 옵션과 수동 검증으로 바꾸기 — 많은 명령에 같은 검증을 복제하고 Commander의 조기 검증을 약하게 만든다.
  - Commander의 모든 문법 오류를 종료 코드 3으로 바꾸기 — 필수 옵션 누락과 무관한 기존 자동화 계약까지 바꾼다.
  - 공통 `Command` 하위 클래스를 만들고 모든 생성부를 교체하기 — 오류 하나를 정규화하기에 변경 범위가 크고 명령 생성 방식을 불필요하게 제한한다.
- **트레이드오프**: Commander가 공개하는 `CommanderError.code` 값에 정책이 의존한다.
  명령 트리를 만든 뒤 모든 하위 명령에 변환을 적용해야 하므로 재귀 적용과 오류별 종료 코드를 테스트로 고정한다.
- **적용 범위**: 필수 옵션 누락의 종료 코드와 중복 출력 방지에만 적용한다.
  다른 Commander 문법 오류의 분류, 오류 문구 번역, 명령별 수동 검증 문구는 바꾸지 않는다.
